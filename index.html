Reference Generator

Generates an APA reference and an RIS bibliography entry for books.

Amazon links: the ISBN is read out of the URL itself, no request is ever sent to Amazon. Goodreads links aren't supported (no public API) — copy the ISBN from the page and paste that instead. Douban (豆瓣) links: since Douban has no public API and blocks direct browser requests, the page is fetched through r.jina.ai, a public read-only page-reader proxy — only the URL you paste is sent to it.

Manual overrides & options

Free key: console.cloud.google.com → enable "Books API" → Credentials → Create API key. Stored only in your browser's local storage, never sent anywhere but Google.
