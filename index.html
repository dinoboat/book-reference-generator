Book Reference Generator

Give it a title, it searches Google Books, Open Library, and Crossref, cross-checks them, and generates an APA reference plus an RIS bibliography entry.

Manual overrides & options

Free key: console.cloud.google.com → enable "Books API" → Credentials → Create API key. Stored only in your browser's local storage, never sent anywhere but Google.
